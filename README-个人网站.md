# 个人求职网站

基于开源模板 [Astrofy](https://github.com/manuelernestog/astrofy)（~1.4k ⭐）定制，面向 **AI 应用开发 / 智能体开发** 方向。

## 快速开始

```powershell
npm install
npm run dev
```

## 文档

- **[内容修改指南.md](./内容修改指南.md)** — 改文字、项目、技能去哪里找
- **[部署说明.md](./部署说明.md)** — 如何让 HR 通过公开链接访问（GitHub Pages / Vercel）

## 内容入口

所有可编辑文字集中在 **`src/site-content.ts`**。

## 技术栈

Astro + Tailwind CSS + DaisyUI
